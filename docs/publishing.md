## Manuell veröffentlichen

1. Auf GitHub ein neues Repository `ga-headset-usb-adapter` anlegen.
2. ZIP entpacken und den Inhalt des gleichnamigen Ordners hochladen; die Ordnerstruktur beibehalten.
3. Die offenen Punkte in `verification.md` bestätigen und die parametrische Originalquelle ergänzen.
4. Erst danach einen finalen Release mit Tag `v1.0.0` erstellen. Den Text aus `releases/v1.0.0.md` verwenden und dessen Entwurfsstatus nach Abschluss der Prüfung aktualisieren.
5. Optional den Buy-Me-a-Coffee-Platzhalter im README ersetzen.
